# ARGO — Agente Quique

Primera base funcional reconstruida desde cero.

Incluye:
- Panel principal.
- CRM básico de clientes.
- Agente Quique como asistente comercial.
- Estructura preparada para catálogos, ofertas, presupuestos y comparativas.
- JavaScript sin dependencias externas.

Abrir `index.html` en un navegador.
